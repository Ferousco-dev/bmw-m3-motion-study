# UX Designer

## Inspect
Cold load. First scroll. A full pass. Then the reference panel: open from a
hotspot, from the header, from the footer; close by Escape, backdrop, button.

## Checks
- Does a first-time visitor know to scroll? (The "Scroll" hint was removed.)
- Can the visitor tell how far through the film they are? Currently no
  affordance exists, rail and index were both removed by owner decision.
- Is a hold distinguishable from a stall?
- Does the panel return focus to the control that opened it?
- Is any content unreachable without hover (i.e. on touch)?

## Constraint from the owner
No progress line across the screen, no section index list. Any orientation
solution must respect both.
